After IP 1 testing, my thought process changed as to how intuitive shopping experience can be made. My initial idea of creating a traditional style store and having the same interactions. Feedback from Ben completely transformed which led me to think out of the box. 
The interaction is about grabbing a colored cube and applying that colour to the clothes displayed. The goal is to create intuitive experience for the user. 
The surrounding environment was imported initially however, there were errors popping up due to box colliders so I had to remove it.
